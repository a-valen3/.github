# Instalação no perfil GitHub

1. Confirme seu usuário atual. Se for `a-valen3`, use o repositório público `a-valen3/a-valen3`.
2. Coloque `README.md` na raiz e a pasta `assets` ao lado dele, preservando os nomes.
3. No GitHub, use Add file → Upload files. Arraste o README e a pasta assets (não o ZIP).
4. Faça o commit na branch padrão do repositório. Abra seu perfil e confira.

Os caminhos das imagens são relativos; funcionam em qualquer usuário, sem editar URLs.
A faixa de confiança usa GIF animado local; o restante do branding usa SVG vetorial, sem JavaScript, APIs, tokens ou serviços externos. A apresentação estática permanece legível se o visualizador não executar a animação. Confira o movimento no perfil publicado: esta entrega não foi validada no GitHub autenticado.
As seções expansíveis usam details/summary. O banner original foi preservado sem cortes ou alterações.

## Tipografia

Os títulos de branding usam letras convertidas em caminhos vetoriais com espaçamento inspirado na referência. Não são uma identificação ou reprodução exata da fonte do PNG. Para igualdade tipográfica, será necessário fornecer o arquivo da fonte ou seu nome e licença. O corpo usa a tipografia nativa do GitHub, pois README não aceita CSS personalizado.

## Checklist final

- O README deve estar na raiz do repositório público que tem o nome do seu usuário.
- A pasta assets deve ser enviada inteira.
- Não envie apenas o ZIP e não cole o texto do Word no lugar do Markdown.
- O GitHub autenticado não foi acessado nesta entrega: publicação e confirmação no perfil continuam pendentes.
- O lettering de VALEN foi redesenhado geometricamente a partir da referência; não foi identificada uma fonte original licenciada.
